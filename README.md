# Expense Tracker

A mobile expense tracking app built with Expo and React Native.

## Getting started

1. Install [Node.js](https://nodejs.org/) and npm.
2. Install dependencies:

   ```sh
   npm install
   ```

3. Start the Expo development server:

   ```sh
   npm start
   ```

Use the Expo Go app to scan the QR code, or run `npm run android`, `npm run ios`, or `npm run web` for a supported target.

## Project structure

- `App.js` — app entry point
- `src/` — application source
- `assets/` — images and other static assets
- `prd.md`, `srs.md`, `erd.md` — product and design documentation

## Notes

Local environment files and generated or installed files are excluded by `.gitignore`.
